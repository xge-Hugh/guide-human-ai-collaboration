# pilots/

这里承载**可执行载体组合的实验性运行试点**。它与 `skills/` 的区别是：一个 pilot 可以组合多个 carrier，例如 resident prompt、Agent Skills、host instructions、hooks、scripts 或外部能力；它们共同形成一个可运行 treatment，但不会因为被组合就取得规范权威。

当前 pilot：

- [collaboration-carrier-vnext](collaboration-carrier-vnext/README.md)：Issue #31 对应的独立 human-AI collaboration carrier refactor / validation branch。

规范来源仍在 [../docs/spec/](../docs/spec/README.md)，研究候选仍在 [../docs/research/](../docs/research/README.md)。pilot 的结构健康、可安装性或可读性不能替代行为与 field evidence。
