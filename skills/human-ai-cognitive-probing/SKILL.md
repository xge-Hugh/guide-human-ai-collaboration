# Selective Cross-Level Epistemic Probing

> Experimental status: research candidate. This Skill tests a candidate control mechanism; it does not make the mechanism a project norm.

Keep this mechanism in the background. Do not present it as a mandatory workflow or checklist.

## Control rule

Use a probe only when all of the following are true:

1. there is a **decision-relevant uncertainty** in the current focal model;
2. continuing in the current representation is unlikely to expose it efficiently;
3. another representation is expected to produce a discriminating or model-building observation at proportionate cognitive/risk cost;
4. the excursion has a clear **epistemic return edge**: what consequential delta is expected to come back to the focal question.

If these conditions are not met, choose **no probe**.

## Probe execution

1. Keep the current workflow focus and authorization boundary explicit in your own control state. A probe does not authorize implementation or change the shared agenda.

2. Select the smallest useful probe by information value, capability fit, risk, reversibility, and cognitive cost—not by “one level deeper” adjacency.

3. A probe may use, for example:
   - one concrete scenario or counterexample;
   - one code/interface/data representation;
   - one runtime trace or source slice;
   - one formal or mathematical representation;
   - one small reversible experiment or action;
   - one alternate domain model.

4. Give the probe one primary epistemic purpose. Avoid constructing a complete lower-level solution when a smaller open representation can discriminate the uncertainty.

5. Extract the **consequential delta** only: what changed, was bounded, was falsified, or remains unknown.

6. Return that delta to the focal model and revise, bound, restructure, or preserve the uncertainty.

7. Stop. A second probe requires a new reason.

## Failure guards

Avoid:
- same-representation saturation when a high-information probe is available;
- premature concretization or silent implementation commitment;
- depth rituals;
- probe overload and representation fixation;
- supporting branches with no return edge;
- agenda drift;
- raw-detail dumping;
- actions that create activity but no epistemic value.

A supporting branch that develops its own objective may become an explicit independent branch. Otherwise, return to the focal question.

## Evidence boundary

Immediate clarity is not proof of long-term learning, reconstruction, or transfer. Record runtime behavior separately from claims about the underlying cognitive model.
