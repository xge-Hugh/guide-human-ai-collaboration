## 7. 可直接复用的模板

实际使用时按任务风险裁剪，不要求每次填写全部字段。

### 7.1 轻量工作包

```markdown
# 工作包：<标题>

- 状态：
- 压力模式：标准 / 加速 / 应急
- 目标：
- 为什么现在做：
- 范围内：
- 范围外：
- 已知事实：
- 未知项：
- 关键约束与不变量：
- 成功标准：
- 人的初始判断：
  - 预测：
  - 依据：
  - 最大不确定性：
  - 改变判断所需证据：
- 首选方案：
- 替代方案或无需替代方案的理由：
- 关键风险 → 验证方式：
- 学习插槽：
- 独立审查策略：
- 文档路由：
- 待人决策：
```

### 7.2 学习插槽

```markdown
## 学习插槽：<名称>

- 学习目标：
- 影响的当前决策：
- 负责文件或符号：
- 允许修改范围：
- 必须保持的不变量：
- 当前起点：选择 / 填空 / 一行 / 代码块 / 函数 / 设计
- 目标掌握层次：M_
- 验收示例：
- AI 当前角色：讲解 / 提示 / 审查，不直接实现
- 提示使用情况：
- 交还条件：
- 迁移练习：
- 后续系统学习：
```

### 7.3 诊断题

```markdown
## 能力诊断：<概念>

- 诊断目的：
- 题目：
- 选项：
  - A：
  - B：
  - C：
  - D：信息不足 / 我不确定
- 人的选择：
- 理由：
- 信心：低 / 中 / 高
- 每个错误选项对应的误解假设：
- 反馈：
- 本题能证明：
- 本题不能证明：
- 是否需要第二个不同情境的证据：
```

### 7.4 类比卡

```markdown
# 类比卡：<名称>

- 目标概念：
- 熟悉来源：
- 对应关系：
  - A → B
  - C → D
- 可以推出：
- 不能推出：
- 断裂点和反例：
- 正式抽象：
- 迁移检查：
- 是否保留：保留 / 修改 / 淘汰
```

### 7.5 结算卡

```markdown
# 结算卡：<任务>

## 任务结果
- 完成内容：
- 验证证据：
- 未验证事项：
- 残余风险及负责人：

## 预测与模型修正
- 初始预测：
- 实际结果：
- 偏差原因：
- 更新后的模型：

## 贡献
- 人的关键贡献：
- AI 的关键贡献：

## 自我效能三账
- 任务结果：
- 个人独立能力：
- 人机协作能力：
- AI 支援级别：A_
- 证据置信度：低 / 中 / 高

## 下一步
- 当前主要瓶颈：
- 一个前置能力：
- 一个通用协作能力：
- 下一次适度练习：
- 可提前识别的信号：

## 沉淀
- 可复用知识：
- 文档路由：
- 技术债务：
- 认知债务：
- 流程债务：
```
