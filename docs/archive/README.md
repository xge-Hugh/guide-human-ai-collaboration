## 使用原则

- 历史文本回答“当时项目如何表述/决定”，不自动回答“现在项目主张什么”；
- 若历史材料与当前正文冲突，以当前正文及明确的 `narrows / supersedes / reclassified` 关系为准；
- 若想把历史做法重新带回当前项目，应重新经过分类、证据校准和必要的规范判断，而不是直接复制旧结论。
