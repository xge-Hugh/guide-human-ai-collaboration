# 协作指导与可替换做法

> 地位：本目录收纳**实现规格目标的可替换方法、配方与操作载体**。它们可以非常有用，但不因写在这里就成为通用合规条件。

当前内容：

- [`interaction.md`](interaction.md)：建构保护、低摩擦提问、理解修复、建设性对抗等交互方法；
- [`representations.md`](representations.md)：文字/表格/图/示例/代码、渐进披露、文档路由与派生表示的使用方法；
- [`templates.md`](templates.md)：可裁剪的工作包、学习、诊断、类比和结算载体。

使用指导时仍服从 [`../spec/norms.md`](../spec/norms.md)。如果换一种做法仍能保护同一规范条件，说明这里的具体方法不是规范本身。

不要为了“使用了某种方法”而展示完整思维框架、问卷或流程表演；方法的价值取决于是否降低当前协作成本并改善实际理解、判断、证据或恢复能力。
