# AI Waiting Practice Card

> Status: quick field-use reference for the temporal-coordination candidate. These are research-informed probes, not current norms.

When AI waiting becomes noticeable, the moves below can be used **alone or in sequence**. Do not treat them as mutually exclusive conditions.

A useful candidate sequence is:

```text
high-engagement AI interaction
→ park one return cue
→ lower-stimulation bridge (paper / simple note)
→ quiet micro-break or light movement
→ re-enter at a meaningful checkpoint
```

This is a **graded-disengagement probe**, not a required ritual. If you can rest immediately, there is no need to add steps.

## 1. Park → downshift → rest (candidate default)

If you have been deeply engaged and stopping immediately feels unnatural:

1. write one short return cue or label;
2. optionally spend a moment with a calmer, single-purpose medium such as paper;
3. then look away, stretch, walk, get water, or rest.

The point is not to produce notes. The note is a **bridge out of active task maintenance**.

**Question afterward:** did the intermediate step make it easier to let go than trying to jump straight from intense interaction into rest?

---

## 2. Quiet micro-break

If there is nothing judgment-relevant to inspect right now:

- look away from the screen;
- stand, stretch, walk a few steps, or get water;
- avoid opening another information stream.

**Question afterward:** did I return calmer and still understand the task?

---

## 3. Park one return question

Before mentally letting go, write only:

> **When the AI returns, what do I need to understand, verify, or decide?**

Use paper or a tiny digital scratch note. Do **not** write a full summary.

**Question afterward:** did this make it easier to stop rehearsing the task and resume later?

---

## 4. Checkpoint review, not continuous monitoring

Do not watch routine AI execution by default.

Re-enter when there is something worth human judgment:

- a changed assumption;
- a failed test;
- conflicting evidence;
- an uncertainty;
- a comparison;
- a proposed decision;
- the final artifact.

**Question afterward:** did watching intermediate steps actually change any judgment?

---

## 5. Defer side chat during pure waiting

If a side-chat question appears while the main thread is still working:

1. write the question in one scratch line;
2. wait for the main thread to return;
3. ask it only if it is still needed.

If the main output has already returned and you genuinely need help understanding it, side chat remains useful.

**Question afterward:** did deferring avoid a rejoin collision or did it make understanding harder?

---

## 6. Add phone friction

During focused collaboration:

- move the phone out of immediate reach, or
- silence unrelated notifications,
- while keeping the agent-completion signal you actually rely on.

**Question afterward:** did this reduce distraction, or did I simply become restless another way?

---

## Optional for conceptual / creative work

Try a low-demand physical activity—brief walking, tidying, looking outside—rather than social media.

Do not assume mind wandering is always beneficial. Treat this as a probe for open-ended thinking only.

---

## What to notice

After a notably good or bad wait, you only need four questions:

1. **Was it easy to re-enter the task?**
2. **Could I understand and judge the returned result well?**
3. **Did I feel calmer or more depleted?**
4. **Did anything I did during the wait actually change a decision?**

If nothing stands out, record nothing.

If something matters, one sentence is enough:

> "Parked one decision before leaving; re-entry was easy."

> "Watched the whole execution; learned nothing useful and felt depleted."

> "Stopped monitoring; missed an assumption change and had to reconstruct."

Strong positive cases and counterexamples are equally useful.
