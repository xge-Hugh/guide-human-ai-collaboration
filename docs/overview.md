# 规范导读

> 地位：导读，**不是**第二份事实源。主张与细则以 [norm/](norm/README.md) 正文为准。  
> 版本基线：文档重组 v0.16-doc（内容源自 workflow v0.15）

## 要解决什么问题

人与 AI 长期协作时，常见两类失败：

1. **交付侧**：方向丢失、无依据假设、自审冒充独立审查、测试全绿却漏真实风险。  
2. **人侧**：阅读与问卷负担过重；熟悉感被误认为掌握；关键判断被流畅答案取代。

本规范同时追求正确交付、人的独立判断、与风险相称的流程成本；**不**以「AI 做完越多越好」为唯一目标。当前默认按交付主线调度、学习为次级轨（D-061），并不表示永久排除学习主目标形态。

## 核心主张（原则级）

完整 17 条见 [目标与基本原则](norm/00-purpose-and-principles.md)。浏览者可先记住：

- 人拥有目的与关键决策权；AI 提供事实、方案与反例，不能用流畅回答取代理解。  
- 关键节点保留人的独立预测或初始判断，再与 AI 结论比较。  
- 证据优先于信心；任务成功、个人独立能力、人机协作能力要分开结算。  
- 从正确抽象层开始，按风险调节讨论、验证与文档深度。  
- 压力可压缩形式，不可取消底线（不可逆操作、重大假设、关键证据与事后债务）。  
- 目的充分、受众适配地自然交流；充分即停止，轻量性优化总协作成本，不等于一味缩短、压高信息密度或强制分片。
- 消除仪式性摩擦，保留建设性对抗；只升级真正会改变方向的冲突。

## 人的默认审查面

完整长文主要服务 AI 执行、恢复与独立审查。人默认只审：

- 目的与关键业务不变量  
- 本轮改变的承重决定  
- 重大风险或未知  
- 待人裁决事项  
- 唯一下一步（及正文链接）

详见 [文档受众与审查面](norm/03-cognitive-mechanisms.md#文档受众与审查面)。

## 常见误解

| 误解 | 规范立场 |
| --- | --- |
| 这是一套必须安装的 Skill / Agent 规则 | 否。规范是内容；Skill/`AGENTS.md` 只是未决的保障形式实验 |
| 照着模板逐项填表才算合规 | 否。模板按风险裁剪；默认从自然表达提取，不把结构成本转嫁给人 |
| 轻量协作就是回答越短越好 | 否。长度、密度、结构和载体按目的、受众、体裁、用户要求与风险调节；完整成果可以是长文 |
| AI 自审等于独立审查 | 否。须在上下文、输入顺序或验证方法上实质隔离 |
| 测试全绿 = 风险消失 | 否。验证按「变化—失效模式—业务后果—证据缺口」匹配 |
| 任务做成了 = 人已掌握 | 否。须分开结算任务结果、独立能力与协作能力 |
