# Temporal coordination research

本 program 研究人和 AI 在时间上的可用性如何影响协作，尤其关注 AI waiting、任务悬置与释放、恢复、blocked-progression polling、side-chat rejoin collision 与 streaming/re-entry。

当前核心对象：

- [`model.md`](model.md)：temporal coordination 候选模型与 evidence boundary；
- [`studies/`](studies/)：field observation 与低负担 practice probes。

当前 practice 只是 research-informed probes，不是规范、固定等待流程或产品要求。该 program 也不假定 waiting 必须成为独立工作流阶段。
