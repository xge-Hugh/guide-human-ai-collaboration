# 研究材料

本目录保存用于校准项目设计、保障机制和证据边界的**研究与参考分析**。

研究材料可以支持风险背景、机制假设或设计启发，但不因被引用就自动成为规范。项目如何解释研究证据见 [`../governance/evidence-policy.md`](../governance/evidence-policy.md)。

当前内容：

- [`assurance-mechanisms.md`](assurance-mechanisms.md)：执行保障机制的社区参考、筛选与取舍研究；
- [`scientific-basis.md`](scientific-basis.md)：从旧规范章节迁出的科学表述依据与参考资料索引。
