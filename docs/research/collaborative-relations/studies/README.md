# Collaborative-relations study index

- **Status**: candidate study program; designs are not results.
- **Purpose**: map each study to the claim family it can discriminate and keep future evidence separate from the conceptual model.

## Planned study sequence

### α — responsibility-relevant delegation

Compare:

1. AI solution substitution;
2. AI execution plus responsibility-relevant human cognitive engagement;
3. extensive AI delegation where the delegated skill is genuinely irrelevant to retained responsibility.

Measure immediate quality/time and later error detection, explanation of consequences, escalation judgment, and transfer to a nearby task.

Primary targets: A5, A6, A7.

### β — independent-signal value

Compare AI-first exposure, minimal independent judgment first, and conditional AI exposure. Stratify human/AI competence, error overlap, risk, and verification cost. Include conditions where useful human signal is latent and activated by AI localization/cues rather than requiring a complete human-first solution.

Primary target: A2; secondary relation to dependence/error-correlation structure.

### γ — bidirectional state settlement

Current highest-priority empirical candidate. Detailed candidate protocol: [`gamma-bidirectional-state-settlement-protocol-2026-09-16.md`](gamma-bidirectional-state-settlement-protocol-2026-09-16.md).

The protocol separates variables that the earlier six-condition sketch conflated:

- **γ-I — settlement form**: final-state only vs full chronological trace vs selective consequential delta, with a common audit return path;
- **γ-II — evidence-access architecture**: surface only vs direct shared artifacts vs indexed/on-demand retrieval, while holding the semantic delta surface constant;
- **γ-III — selector stress test**: oracle-selected delta vs executor-selected delta with and without auditability, conditional on selective settlement showing value in γ-I.

Run in both directions: AI executes → human regains usable state, and human executes → AI regains usable state. Begin with frozen replay fixtures so settlement architecture changes while the underlying execution episode remains constant.

Measure consequential-state reconstruction, accept/inspect/repair/escalate judgment, confidence calibration, validation-path reconstruction, missed/noisy evidence, recipient and executor coordination cost, clarification/retrieval actions, later evidence location, and reconstruction of why confidence changed.

Primary targets: A3, A3a, A3b, A10, A12, A14. γ estimates state-coordination costs relevant to A9 but does not itself establish the allocation claim.

### δ — adaptive representation trajectory

Compare permanent familiar-language translation, native representation immediately, native representation with strong mediation that fades, and representation selected only for immediate efficiency.

Measure immediate performance, coordination time, error detection, inference from the native representation, later unaided verification, transfer, and continuing dependence on translation.

Primary targets: A11, A13.

### ε — addressability versus usable prerequisite structure

Cross knowledge type with support condition.

Knowledge types:

- reference-like information (syntax, parameter names, exact flags, version-specific constants);
- dependency-like information (conceptual invariants, causal relations, failure semantics, constraints repeatedly used downstream).

Support conditions:

1. lookup/address only;
2. minimal concept index plus lookup;
3. usable conceptual schema plus lookup;
4. fuller instruction/internalization support.

Measure retrieval frequency, reasoning latency, error detection, consequence explanation, nearby transfer, performance when retrieval is temporarily unavailable, and cognitive cost.

Primary targets: A14, A15, A16.

### ζ — cross-participant cognitive placement

Human-side conditions:

1. full instruction/internalization support;
2. usable schema plus external reference;
3. compact index plus external reference;
4. lookup-only.

AI-runtime conditions:

1. full relevant theory resident;
2. compact recognition kernel plus conditional Skill/procedure;
3. compact index plus canonical retrieval;
4. external resource only with no resident recognition cue.

Cross with reference-heavy, recognition-critical, reasoning-compositional, and volatile/source-sensitive tasks.

Measure missed/irrelevant retrieval, reasoning latency, context/attention cost, error detection, transfer, and recovery when an external store is unavailable.

Primary targets: A16, A17. Related synthesis: [`cognitive-placement-bridge-2026-09-15.md`](cognitive-placement-bridge-2026-09-15.md).

## Evidence rule

A study should not be described as validating the whole collaborative-relations model. Results must be connected to the exact claims and boundary conditions they discriminate. Null or mixed results are expected to narrow the model rather than being hidden by aggregate task success.
