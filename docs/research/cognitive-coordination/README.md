# Cognitive coordination research

本 program 研究：人和 AI 如何在**局部、可修正、情境化的任务模型**上协调，以及认知资源如何在解释、预测、判断、执行、验证、修正与恢复之间分配。

当前核心对象：

- [`model.md`](model.md)：认知协调候选模型；
- [`evidence-review.md`](evidence-review.md)：项目内观察与外部研究的独立校准；
- [`design-diagnoses/`](design-diagnoses/)：由候选模型导出的运行/设计缺口诊断；
- [`studies/`](studies/)：cloud semantic replay、Skill field pilot、reconstruction-surface 等 study。

## Authority boundary

这是 research program，不是 current collaboration spec。单个候选机制即使进入 Skill pilot，也不因此成为 current norm 或已验证事实。

跨 program construct（例如 reconstruction）可以被其他 inquiry 引用；目录不表示永久概念所有权。
