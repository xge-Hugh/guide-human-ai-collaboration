## 一句话主张

人和 AI 在协作中都只能持有**局部、可修正、受情境影响的任务模型**。高质量协作不要求双方内部模型完全相同，也不要求人持续参与每个认知动作；它要求在会改变判断、行动、责任、学习、审查或恢复的地方，以成本相称的方式让关键模型差异、证据边界和未知变得可观察、可检验、可修正，并把稀缺的人类认知资源分配到其即时与长期价值较高的地方。

该模型目前最适合作为现有“价值/权威与认识论约束”与“策略/工作流/保障实现”之间的**候选机制层**：它试图解释许多现有规则为什么有效，但不能推出人的最终权威、证据优先、来源权威、风险接受或法律/专业资格等上层约束。

---

## 1. 为什么提出这一模型

项目当前已有许多经过真实协作逐步形成的规则，例如：

- 承重判断前不要由 AI 先封闭完整候选空间；
- `嗯嗯`、沉默、继续对话不能单独证明理解、同意或授权；
- 问题、确认和模板只有在答案可能改变重要行动时才值得打断人；
- 风险、可逆性、不确定性、熟悉程度和压力应调节协作强度；
- 示例、故事、预测、反例、先例与抽象层都只是可替换的认知工具；
- 独立审查应隔离相关假设/证据路径，而不只是换角色名称；
- 复盘应检验“为什么发生”，而不是生成漂亮总结；
- 重复协作要避免人的持续责任与可实际行使的能力基础长期脱节；
- “轻量”是降低无相称价值的认知、行动、等待与维护成本，而不是机械变短。

这些规则目前可以各自成立，但它们看起来可能共享更深的机制。候选模型尝试回答：**这些规则究竟在保护、建立或修复什么？**

起点来自一个学习问题：一次“已经理解”的概念在一个月后可能只剩术语记忆，重新阅读定义也不能恢复当时可用于判断和预测的关系网络。因此：

> `信息被保存` ≠ `理解可在未来被重建`。

随后在“interface/API”与“回归均值”的两次不同类型学习案例中，观察到一种相似过程：旧模型先对具体情况产生预测或解释，区分性案例暴露隐藏假设，模型被修正，再由术语或正式定义压缩/索引已经形成的结构。该过程提供了支持性观察，但**不是教学效果实验，也不能证明此方法普适或优于直接解释**。

## 2. 核心对象：任务相关的可用模型，而不是完整心理画像

这里的“模型”不是要求参与者拥有显式、形式化或可完全说出的心理模型。它只表示一种在当前范围内足以支持某些操作的内部结构，例如：

- 解释一个对象/关系；
- 对条件变化作预测；
- 判断方案、风险或证据；
- 执行、纠错或审查；
- 识别边界、未知或需要升级求助的地方。

模型可以部分是隐性的。专家的“这里不对劲”可能先以错误检测或动作选择表现出来，而不是完整语言解释。因此：

> `无法完整说出模型` ≠ `没有可用模型`。

协作只应跟踪**最小任务相关状态**，例如当前假设、解释、未知、重要模型差异与所需支援；不能把一次任务观察升级成“这个人是什么类型的思考者”之类永久心理画像。现有能力模型的情境化、支援归因与反永久标签约束继续优先。

## 3. 候选认知协调操作

这些是机制函数，不是用户必须逐项完成的流程，更不是新问卷。

### 3.1 激活（activation）

让当前任务真正需要的旧经验、假设、关系或上下文重新进入可用状态。

可能载体：一个具体案例、一句历史判断、原始证据、旧决策的关键矛盾、代表性代码片段。

### 3.2 外显（externalization）

通过预测、解释、选择、行为、例子或证据请求，让内部模型的一部分后果变得可观察。

外显不是为了“证明人有思考”，而是当隐藏差异会改变后续行为时，为协调取得相称证据。

### 3.3 判别（discrimination）

选择能够区分两个或多个重要模型的低成本案例、问题、反例、测试或观察。

因此，一个问题的价值不在于它是否属于苏格拉底式、5 Why 或其他成熟方法，而在于：

> 它能否以相称成本暴露会改变方向、风险、权限、验证、理解或责任的模型差异？

### 3.4 与外部证据接触（evidence contact）

双方模型可以高度一致却同时错误。因此模型协调不能替代真实证据、来源、运行环境、专业判断或独立测量。

预测与现实不一致也不自动说明高层模型错误；可能是噪声、测量错误、边界超出、遗漏变量、实现缺陷或世界发生变化。预测误差应触发认识论调查，而不是机械重写模型。

### 3.5 修正与定界（revision / bounding）

当区分性证据出现时，明确哪些关系被修正、哪些仍保留、适用范围在哪里、还有什么未知。

好的模型修正不是把一个新句子覆盖旧句子，而是能够解释：

```text
原来为什么会这样判断
→ 什么案例/证据无法解释
→ 哪个关系或假设需要改变
→ 新模型能解释什么
→ 在哪里仍可能失效
```

### 3.6 重建（reconstruction）

**候选新概念。** 指在上下文衰减、任务中断或跨会话之后，在指定线索、来源和支援条件下，能否重新生成足以解释、预测、判断或行动的任务模型。

重建不是把旧信念原样恢复。旧模型可能已经过期；更安全的目标是：

> 恢复足够的推理路径，使参与者能够重新判断该模型现在是否仍适用。

因此重建材料可能需要保留：原假设、区分性案例、修正原因、适用边界、来源/时间以及什么变化会要求重新验证。

### 3.7 策略性接触（strategic exposure / substrate contact）

**候选新概念。** AI 可以承担大量生成、检索、脚本编写或底层执行，但人的高层模型若长期只接触 AI 二次压缩后的摘要，可能失去：

- 对 AI 表示是否忠实的校准；
- 发现异常与边界线索的机会；
- 从底层现象形成新抽象的原始材料；
- 判断何时抽象层开始泄漏的经验；
- 与持续责任相关的纠错/审查能力。

因此在收益与成本相称时，可以让人**选择性接触承载结论或高信息价值的底层片段**，而不是要求人重做 AI 的工作。

例如接口调试中：AI 可以写完整测试脚本，人不必手写复杂脚本；但查看真实请求、关键 assertion、失败/重试语义或一个异常响应，可能帮助建立对接口契约的真实模型。

> `低抽象层` ≠ `低认知价值`。

策略性接触也不意味着“原始材料越多越好”。代表性、判别性、来源独立性和认知成本仍需权衡。

### 3.8 生产性分歧（productive divergence）

**候选新概念。** grounding 的目标不应被理解成让人和 AI 尽快拥有同一模型。有些差异应暂时保留，因为过早收敛会损害：

- 独立审查；
- 创造性探索；
- 替代假设；
- 对共同错误来源的抵抗；
- 发现证据缺口的能力。

更准确的目标可能是**相互模型可辨识性（mutual model legibility）**：双方知道重要假设、预测和分歧在哪里，以及什么证据或责任边界决定下一步。结果可以是同意，也可以是被清楚识别、暂时保留的不同模型。

### 3.9 认知分配（cognitive allocation）

人的工作记忆、注意力、疲劳预算与时间是稀缺资源。健康协作既不最大化人的参与，也不最大化 AI 的替代，而是判断某个认知动作的**直接和间接边际价值**。

需要考虑的价值可能包括：

- 当前方向/风险/价值判断；
- 降低不确定性；
- AI 表示与来源的校准；
- 独立错误检测；
- 未来责任相关能力；
- 恢复/重建价值；
- 从底层接触中发现新线索的可能性。

成本包括认知负担、时间、疲劳、打断与机会成本。

这不是可执行评分公式。它只约束一种常见过度简化：

> `AI 做得更快` 本身不足以证明应该长期完全委托；
> `人仍有最终权威` 也不足以证明应该让人参与所有低价值步骤。

尤其要避免一个反向失效：为了只让人处理“高价值判断”，把所有底层现象都经 AI 过滤后再呈现，最终使高层判断本身失去与现实校准的来源。

### 3.10 选择性跨表示认知探针（selective cross-representation epistemic probing）

**候选扩展机制。** 2026-08-30 的历史证据回放最初以“选择性跨层认知探针”描述一个运行歧义：什么时候应该离开当前表示去构造另一种表示、是否必须逐级下降、进入更低层是否意味着 workflow phase 已改变，以及探索何时必须返回。

2026-09-06 的进一步讨论显示，**“跨层”仍容易让人误解为只有向下钻取才产生增量**。实际有价值的 probe 可以：

- **向下**：从架构/需求进入代码、日志、真实请求、底层证据；
- **向上**：从局部技术问题抽取更高层 business model、incentive、system architecture、governance relation，以改变当前判断；
- **横向**：进入另一个 representation、stakeholder model、alternative formulation 或同层但不同视角；
- **跨领域**：借 apparently unrelated precedent、analogy 或外部理论形成可返回当前任务的新关系。

因此 task understanding 更适合被视为多个局部、可修正表示之间的**图状协调**，而不是沿单一抽象阶梯向下完成。软件开发 L0–L4 仍可作为 domain routing heuristic，但认知探针可以选择相邻或非相邻、上/下/横向或跨领域表示，只要该 representation 预计能以较低总认知成本暴露一个会改变当前模型的关系。

最小语义：

~~~
focal model M0
    ↓
decision-relevant uncertainty / weak relation U
    ↓
select minimal probe P into representation R
    ↓
externalize / discriminate / synthesize / contact evidence
    ↓
consequential delta Δ
    ↓
return Δ to M0
    ↓
revise / bound / restructure / reweight / preserve unknown
    ↓
M1
~~~

这里的 **Δ 不限于新增事实**。一个新抽象、business relation、structural analogy 或此前看似无关的连接，只要能改变 focal model 中某个关系的权重、边界、优先级或可解释性，就可能具有 epistemic return value。

关键边界是：

- **workflow focus 与 representational direction 正交**：任务理解阶段可以临时进入更低、更高、横向或跨领域 representation，只要仍服务于当前目的、范围、不变量、判断或未知；
- **probe 不等于 implementation commitment**：构造另一表示本身不授权修改真实系统，也不意味着阶段自动切换；
- **方向由判别/重构价值决定，不由 adjacency 或“越底层越真实”决定**：一个 business model 可能比更多代码细节更能解释架构取舍；一个真实日志也可能比高层抽象更能暴露错误；
- **supporting excursion 需要 epistemic return edge**：进入另一表示前，应能说明它预计回答/重构当前哪个问题；得到 consequential delta 后带回 focal model。若探索形成独立目标，应单独路由；若既无返回价值也无新目标，则更像 agenda drift；
- **probe 应保持最小充分**：完整 lower-level 草案、无边界的 abstraction hopping 或连续多表示转换都会增加 integration burden、fixation 与 working-memory load；带回一次 Δ 后重新判断是否需要下一次 probe；
- **允许 no-probe**：低风险机械事项、简单事实、已有清楚 grounding 或另一表示没有新增判别价值时，直接继续当前表示是正确行为。

该机制不是新的用户可见流程，也不要求每次协作都显式执行。它更像 cognitive allocation、activation、externalization、discrimination、evidence contact、revision 与 reconstruction 的组合控制：认知分配决定是否值得离开 focal model，probe 构造/接触另一 representation，Δ 被带回并修正当前模型；若某条跨表示关系具有较高未来价值，还可以保留为 bridge cue，支持后续 activation、external knowledge retrieval 或 human reconstruction。

2026-08-30 的历史回放主要检验原“cross-level”版本，见 [选择性跨层认知探针：历史证据回放与边界测试](studies/cross-level-epistemic-probing-replay-2026-08-30.md)。当前 2026-09-06 的“cross-representation”扩展**尚未经过同等历史回放与行为实验**，因此是对候选模型的语义扩展，不应把旧 study 当成完整验证。

## 4. 与现有项目结构的候选关系

该模型不应成为新的最高原则。当前更合理的层次是：

```text
价值 / 治理
目的、人类最终权威、责任、授权、风险接受
        ↓
认识论约束
证据、未知、来源、独立性、证明边界
        ↓
认知协调候选模型
激活、外显、判别、证据接触、修正、重建、
策略性接触、生产性分歧、认知分配、选择性跨表示探针
        ↓
自适应控制
风险、可逆性、不确定性、熟悉度、能力需求、压力、目的
        ↓
策略 / 工作流
问题、示例、抽象层、表示、行动、审查、复盘、学习
        ↓
执行保障 / 载体
Skill、提示、状态、Agent、Hook、eval、检索等
```

其中：

- **人的最终权威**是项目价值承诺，不能由认知模型推出；认知模型只能解释怎样让这种权威具有实际可行使的判断基础。
- **证据、来源与独立性**是更上层的认识论边界；双方模型一致不等于真，两个参与者同意也不等于两份独立证据。
- **风险/压力/可逆性**决定认知协调值得投入多少，而不是由认知模型本身产生。
- 交互方法应尽量保持在后台：不能把“激活→预测→反例→修正→重建”机械展开为人的固定作业，否则会复现项目已有的问卷/方法仪式失效。
- **runtime capability formation 是相邻但不同的问题**：本模型描述什么认知函数可能有价值；[`../runtime-capability/`](../runtime-capability/README.md) 研究什么 context、retrieval、Skill、guidance 或外部 state 能让真实模型可靠激活这些函数。

## 5. A/B/C：本候选模型的形成方法

本轮没有从“模型听起来漂亮”直接修改规范，而是使用一个候选的三段式模型开发方法。

### A — 与已知连接 / derivation audit

逐项检查现有规范、适应模型、工作流与评估：新模型是否真正解释了已有机制，还是只换词重述。

结果：它对建构保护、grounding、抽象层、表示、短反馈回路、学习、总认知成本、建设性对抗、冲突处理和工作流迭代提供了较强统一解释；但无法推出人的最终权威、来源权威、风险接受、真值与法律/专业资格。

### B — 反例与边界 / adversarial boundary test

主动寻找模型会给出坏建议的情境，例如：机械低风险任务、真正初学者、疲劳/应急、专家隐性能力、开放世界噪声、创造性任务、双方同源错误、过时重建、过度心理画像与元方法仪式化。

结果：模型被显著缩窄。`总是预测优先`、`共享理解=模型收敛`、`只保留高层认知`、`重建线索天然有益` 都被否定。

### C — 新后果 / novel-consequence audit

只保留现有规范不能干净表达、且通过 A/B 后仍有区分价值的候选后果。

当前最强的候选后果包括：

1. **重建性**：即时理解与未来可恢复判断不是同一性质；
2. **策略性接触**：为了保留高层判断能力，有时需要选择性接触高信息价值 substrate，而不是让 AI 永久过滤全部底层现象；
3. **生产性分歧**：协调不等于模型收敛，重要差异可以在可辨识、可检验条件下保留；
4. **选择性跨表示认知探针**：有效认知增量不只来自向下钻取，也可能来自向上抽象、横向重构或跨领域连接；关键是能否把 consequential delta 带回 focal task model，而不是 probe 的方向本身。

这些仍是候选研究对象；是否进入 specification、guidance 或 carrier，需要独立 evidence 与 downstream decision。
