# Assurance research

本 program 研究：**当前协作规范如何在真实运行中被可靠触发、观察、检查、恢复和评价，以及不同 carrier/机制能提供什么保障。**

它包含社区/外部机制研究、v1 field pilot、v2 controlled replay、grader/runner isolation 分析与原始 study evidence。

## Authority boundary

- 本 program 不是当前规范；当前要求见 [`../../spec/`](../../spec/README.md)。
- Skill、runner、grader、状态或其他 carrier 被实现，不等于其运行保障已被证明。
- study 成功、最终任务成功或结构审查通过，不能自动外推为普遍可靠。
- [`mechanisms.md`](mechanisms.md) 是机制与外部实践研究；[`studies/`](studies/) 保存项目实际 study/pilot 的设计、instrument、evidence 与 interpretation。

当前研究判断和证据强度服从 [`../../governance/evidence-policy.md`](../../governance/evidence-policy.md)。
